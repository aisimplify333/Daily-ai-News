# Reusable production library

The standalone ElevenLabs workflow creates six 10-second location atmospheres,
a three-second sonic identity and a two-second Rufus entrance. It assembles three
promotional candidates from existing published cast clips and their actual follow CTA.
No cast recreation, extra episode production, or social posting occurs.

Run-once marker triggers generation; ordinary source edits do not. Re-running the
same Actions attempt is disabled to prevent uncertain paid retries. Existing assets
are reused; a prior incomplete request stops further generation for inspection.
Short requests reserve 1,000 credits each from a 10,000-credit batch budget. Actual
cost headers are recorded when available. This is an application budget, not an
account-side billing cap. No subscription changes or purchases are made.

Assets and the manifest are committed even after a partial failure and also exported
as an artifact. Daily production is independent. Location beds, entrance and signature
are candidates requiring audio review before insertion into daily masters. Keep beds
brief and quiet; only use locations clearly framed by the script. No laugh tracks.

Next activation: select reviewed assets, mix a short location entrance below Rufus's
voice with a quick fade, preserve timing and chapter markers, and retain plain-audio
fallback. Use a consistent signature across promos, then compare follow-through and
return listening when platform analytics are available. No conversion or listening
quality has been measured by this builder.

Existing sponsor exchanges continue through the cast's established Gemini/Grok
voices. Holiday specials require fresh sourced scripts; credits are not spent on
speculative news.
