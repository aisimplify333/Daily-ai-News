# The AI Edge: a noticeable step change

Owner direction, November 19, 2026: go ten steps, with an audible and visible difference.

Production mandate: incorporate all ten workstreams. Missing editorial evidence is a flag, never a production stop. Keep accepted improvements within each segment; reject a regressive replacement locally while retaining improvements elsewhere. After bounded repair, continue with unresolved review flags. A provider or review failure preserves the usable script. Actual source/fact auditing and playable-audio checks still run.

Final editorial acceptance now reports `blocking: false` and `publication_allowed: true` independently of its honest review verdict. Completed-master recovery also treats editorial evidence as advisory. Neither an absent citation nor an unavailable reviewer may discard a completed usable show.

The creative promise: consequential AI reporting with three friends whose company is worth returning for. Keep three distinct core stories and the separately produced Jamie transformation feature. Preserve approved cast identities and signature music.

## Implementation in this change

- Storyboards now specify scene shape, sustained exchange, factual turning point, pacing contrast, portable exchange and a concrete ending answer. Existing writers and scene editors receive the enriched scene plan.
- The writer is directed to develop two standalone exchange candidates while retaining attribution and uncertainty.
- The existing bounded scene-review request now returns ten advisory producer observations, each with actual script line references. A local resolver rejects invalid references and marks evidence changed by repairs as needing review. No extra model request or new publishing gate is added; prompt/output token cost can change.
- README corrected to the current three-story format.
- Six focused tests cover missing and malformed evidence, false references, changed citations, request count, and provider failure. Changed Python files compile locally. Full repository CI remains a separate requirement.

These are implementation changes, not a claim that all ten workstreams are complete. Sound redesign, final-master listening, promotional uploads, authenticated analytics and revenue measurement are outstanding. Existing production includes work in these areas, but this change has not verified their live results.

## Release and evaluation

Run offline CI before integrating. Use the next normal production to inspect storyboard, final dialogue and producer evidence; follow the final script hash when interpreting a report. Missing advisory fields cannot fail publication. Rehearsal excerpts can demonstrate the intended difference, but the rendered full episode determines whether it worked.

Listen to the opening, one sustained exchange from every story, both recurring features, every transition and the closing. Record timestamps and specific strengths/defects. Compare against the prior episode using the same questions. Do not assign a numerical entertainment rating without listening. A producer observation whose quotation survived editing is still a model opinion, not a quality certification.

For distribution, distinguish generated, rendered, uploaded, publicly playable, and measured. Use actual publication links and account analytics. Promotion assets sitting in the repository do not establish audience exposure.
